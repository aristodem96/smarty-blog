# Використання ІІ

Інструмент: Claude Code (модель Claude Opus 5.5).
Принцип: архітектурні рішення приймає автор, ІІ пропонує варіанти та виконує рутину
після погодження. Кожен етап автор перевіряє і комітить сам.

| Етап | Що зробив ІІ | Що вирішив / зробив автор |
|------|--------------|---------------------------|
| 0 | Склав `.gitignore` з поясненнями груп правил. Згенерував каркас документації (`CLAUDE.md`, `docs/*`), `.claude/settings.json`, власні команди за специфікацією автора. Підготував 2 варіанти структури та чернетку схеми БД. | Сформулював правила роботи, план етапів, критерії якості, склад документації. Обрав структуру «шари за типом» (ADR-002), slug в URL замість id і `description` як TEXT замість запропонованого ІІ VARCHAR(500) (ADR-003). |
