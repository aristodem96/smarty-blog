# Використання ІІ

Інструмент: Claude Code (модель Claude Opus 5.5).
Принцип: архітектурні рішення приймає автор, ІІ пропонує варіанти та виконує рутину
після погодження. Кожен етап автор перевіряє і комітить сам.

| Етап | Що зробив ІІ | Що вирішив / зробив автор |
|------|--------------|---------------------------|
| 0 | Склав `.gitignore` з поясненнями груп правил. Згенерував каркас документації (`CLAUDE.md`, `docs/*`), `.claude/settings.json`, власні команди за специфікацією автора. Підготував 2 варіанти структури та чернетку схеми БД. | Сформулював правила роботи, план етапів, критерії якості, склад документації. Обрав структуру «шари за типом» (ADR-002), slug в URL замість id і `description` як TEXT замість запропонованого ІІ VARCHAR(500) (ADR-003). |
| 1 | Запропонував варіанти стеку й версій; написав `Dockerfile`, `entrypoint.sh`, конфіг Nginx, `docker-compose.yml`, `composer.json`, smoke-тест; перевірив запуск, роутинг Nginx і ідемпотентність рестарту. | Обрав Nginx + PHP-FPM, Composer у контейнері, ініціалізацію через entrypoint (замість Makefile, який рекомендував ІІ). Поставив під сумнів пропозицію новішого PHP → компроміс: мінімум 8.1 у composer.json, 8.3 у Docker. |
| 2 | Запропонував варіанти механізму міграцій; написав SQL-міграції, `bin/migrate.php`, `Database`, конфіг; виявив проблему `updated_at ON UPDATE` з лічильником переглядів; перевірив ідемпотентність і `--fresh`. | Обрав нумеровані міграції з таблицею `migrations`, `--fresh` без down-міграцій, перенесення підключення до БД в етап 2, перехід на `utf8mb4_0900_ai_ci`. |
| 3 | Запропонував варіанти роутера, формату відповіді, DI, Request, layout; написав Core-класи, контролери-заглушки, шаблони, bootstrap; перевірив маршрути, 404/500, HEAD/POST, автоекранування. | Обрав `Response`-об'єкт замість рекомендованого ІІ повернення рядка (з розрахунку на масштабування), клас-роутер, ручне збирання залежностей, `Request`. |
| 4 | Запропонував варіанти джерела даних, транслітерації, зображень і поведінки сидера; написав `BlogSeeder`, `Slugger`, `bin/seed.php`, тексти-заготовки українською; згенерував 8 SVG одноразовим скриптом (не в репозиторії); знайшов і виправив помилку транслітерації після апострофа; перевірив детермінованість і `--if-empty`. | Обрав власний генератор замість Faker, українську транслітерацію замість `ext-intl` чи англійського контенту, SVG у репозиторії, перестворення даних + `--if-empty`, клас сидера з окремим namespace. |
