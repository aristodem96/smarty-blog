# AI usage

Tool: Claude Code (Claude Opus 5.5 model).
Principle: the author makes architectural decisions; the AI proposes options and does routine work
once the approach is agreed. The author reviews and commits every stage personally.
Each row maps to the commit(s) in `git log` that contain that stage.
